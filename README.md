# League1-xg-dashboard
This tool combines an Excel database with a web dashboard to make football analytics simple. It processes match xG and results across League 1 and the Championship, auto-calculating real-time points and xGD. The dashboard features comparison radars, scatter plots, and live CSV updates to quickly evaluate true team form.
The dashboard HTML isnt updated but you can save the 1st raw data sheet as a CSV and then upload it on the button to then keep it up to date.
